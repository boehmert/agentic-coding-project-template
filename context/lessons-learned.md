# Lessons Learned – Compound Learning Log

This document is the **collective memory** of the agent team.
Every agent reads it at session start. Every agent that learns something relevant adds an entry.

The principle: each new agent session is smarter than the previous one.

---

## Format

```
### [YYYY-MM-DD] [Agent-Name] – [Short Title]
**Context:** [In what situation was this learned?]
**Finding:** [What turned out to be true / false / surprising?]
**Application:** [How should future behavior change? (concrete, actionable)]
**Category:** [Tech | Business | UX | Legal | Infrastructure | Privacy | Process | Architecture]
```
